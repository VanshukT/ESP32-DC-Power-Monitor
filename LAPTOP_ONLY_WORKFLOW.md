# Laptop-only preparation workflow

You can understand the firmware, practice the screen layout, prepare the repository, and learn the measurement theory before buying any parts. You cannot perform real voltage/current measurements without the physical INA219 circuit.

## Step 1 — Read the project material

Read these in order:

1. Root `README.md` for the short project overview.
2. `PROJECT_REPORT.md` for the principle, architecture, method, and limitations.
3. `COMPONENTS_AND_PURCHASE_CHECKLIST.md` to understand each part before ordering.
4. `VIVA_PREP_HINGLISH.md` to practise explaining the project.
5. `hardware/connection-diagram.png` to learn the power path and logic wiring.

## Step 2 — Practise the OLED firmware in Wokwi

1. Open https://wokwi.com/ in a browser.
2. Create a new ESP32 project (ESP32 DevKit / ESP32 DevKitC).
3. Copy the contents of `src/esp32_dc_power_monitor.ino` into the sketch editor.
4. Add the OLED from the parts list, or replace `diagram.json` with `simulation/diagram.json`.
5. Add `Adafruit GFX Library` and `Adafruit SSD1306` if the simulator asks for libraries.
6. Keep `SIMULATION_MODE` equal to `1`.
7. Run the simulation and observe the OLED and Serial Monitor.

Expected: the screen refreshes with voltage/current/power-like demonstration values. These are generated by the sketch and are not readings from an INA219 or an electrical circuit.

## Step 3 — Understand the code

- `setup()` starts Serial, I²C, and the OLED. In physical mode it also starts INA219.
- `readPowerReadings()` obtains synthetic demo values in simulation mode or reads the real sensor in hardware mode.
- `updateDisplay()` formats the readings for the OLED.
- `printToSerial()` prints the readings to the laptop Serial Monitor.
- `loop()` refreshes the output every 500ms.

Try changing only the display title or update interval in simulation mode. Keep the generated demo values labelled as demo values.

## Step 4 — Prepare the GitHub repository

Follow `GITHUB_UPLOAD_GUIDE_HINGLISH.md`. Keep the repository status honest: **Planning / display simulation; physical hardware not built yet.**

## Step 5 — After parts arrive

Only then follow the connection diagram, check the module ratings, assemble the circuit with power OFF, and switch to `SIMULATION_MODE = 0`. Validate with a multimeter before claiming measured performance.
